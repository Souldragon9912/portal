    Dashboard Settings

    Need a Client ID? Click for setup instructions
    1. Go to console.cloud.google.com and create a New Project.
    2. Go to APIs & Services > Library, search for Google Calendar API, and click Enable.
    3. Go to OAuth consent screen, pick External, name the app "Dashboard", and save.
    4. Go to Credentials > Create Credentials > OAuth client ID.
    5. Set Application Type to Web application. Under Authorized JavaScript origins, enter your dashboard address (e.g., http://localhost or your server IP).
    6. Click Create, copy the Client ID, paste it into the field above, and click Save Configuration.
